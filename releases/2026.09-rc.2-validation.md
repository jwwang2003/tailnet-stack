# Integrated 2026.09 RC2 validation

Date: 2026-09-14. Status: **candidate, not promoted to production**. Supersedes the RC1 candidate; `versions.lock.yaml` keeps `status: candidate` and `compatibility_verified: false` because full Feishu lifecycle synchronization still waits for two tenant scope grants.

## Changes since RC1

| Area | Change | Source |
| --- | --- | --- |
| Casdoor | `update-user?columns=...` decoded the request into a shallow copy of the stored user, so ordinary employees could change admin-only Properties (including `headplane_role`) and same-length Groups. Fixed with `User.DeepCopy`; native syncer logs print identifiers only; Lark pagination rejects empty/repeated cursors and more than 10000 pages. | casdoor `fde2cf8f` |
| Worker | `--permissions` scope preflight with grant link; `lifecycle_mode: staged` (native import plus descriptive profiles without status, automatic upgrade to full lifecycle); Headscale node/preauth-key revocation when an account is blocked, retried from durable state; `--offboard` immediate containment; heartbeat file and Compose healthcheck; transport errors name the OS reason. | integration `5a8ec50` |
| Casdoor configuration | `scripts/casdoor-harden.py` (directory-managed account items Admin-only, empty provider binding rule, no Face ID/WebAuthn/code sign-in) and `scripts/verify-casdoor-authz.py` (ordinary-user regression probe). | integration `5a8ec50` |
| Deployment | Casdoor `/files` persisted under the runtime directory; worker healthcheck; candidate images retagged `2026.09-rc.2`; documentation updated for every item above. | integration `5a8ec50` |

Headscale (`59516776`) and Headplane (`fb7ae3e`) sources are unchanged from RC1; their RC2 images are the RC1 image IDs retagged.

### Existing-access revocation (live Headscale API, local sandbox)

The worker's Headscale client matched the sandbox OIDC user by provider identifier (`issuer/subject`), listed nodes (none enrolled at test time), and expired a throwaway preauth key through `POST /api/v1/preauthkey/expire`; the key's expiration moved to the call time. ### Backup and restore rehearsal

A real isolated rehearsal ran on the development WSL host with rootless Podman 4.9.3 and podman-compose 1.6.0 behind a PATH shim that supplies the Docker Compose v2 subcommands the scripts use (`ps --services --status`, `cp`, `create`, literal `--profile '*'`). Projects `rehearsal-a` and `rehearsal-b` were created from `deploy/site.example.json`, seeded with an extra Casdoor organization, application and user plus a Headscale user and preauth key, and torn down afterwards; the `fysics-local-*` sandbox was untouched.

| Step | Result | Duration |
| --- | --- | --- |
| `scripts/backup.sh` | Stopped Headscale and Casdoor, dumped PostgreSQL, archived the runtime (socket excluded, SQLite without WAL), restarted both services healthy; SHA-256 printed | 6.6 s |
| `scripts/restore.sh` into a new directory and project | Archive validated, files restored byte-identical (16/16), only `compose.env` rewritten (project, runtime path), database imported, proxy container created but not started | 13.1 s |
| Data check before starting applications | Rows, 44 tables, Casdoor `cert-built-in` certificate and private key, built-in client credentials identical to the baseline | |
| Restored applications | Casdoor served the seeded organization/application/user with the same IDs; Headscale listed the seeded user and preauth key (same value); noise private key checksum identical; same image IDs | Casdoor reachable 5 s after start |
| Negative paths | Existing destination refused with "nothing was overwritten"; existing project refused without creating the directory | |

Clean-path recovery time for this data size is under one minute. The scripts require Docker Compose v2 semantics: unmodified podman-compose stops `backup.sh` before any service is touched, and stops `restore.sh` after the database import at `create proxy`. Rootless Podman also needs `userns_mode: keep-id` for the 0600 configuration files; neither applies to the Docker Engine deployment target.
