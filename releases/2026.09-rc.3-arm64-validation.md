# RC3 ARM64 candidate

Status: **candidate; production acceptance pending**. This candidate follows RC3
`507db66`. The deployment host reports `aarch64`, while the existing RC3 image
bundle targets `linux/amd64`. A separate `linux/arm64` build uses architecture
specific image tags and preserves the original amd64 bundle.

## Changes and checks

- Integration `df059c1` selects ARM64 and distinct image tags; product sources
  initially remained unchanged.
- Integration `0b1a648` fixes Casdoor hardening against its real application wire
  schema. Explicit sign-in methods disable Face ID, WebAuthn and verification-code
  sign-in; a disabled sentinel prevents empty-list defaults from re-enabling
  Face ID. Seven regression tests pass.
- Integration `5e2e1f7` reads renderer product-image defaults from the source lock,
  validates them before runtime writes and preserves operator image pins.
  Architecture-aware bundle tests retain foreign-platform rejection checks.
  Full integration suite: **188 tests pass**, plus shell syntax and whitespace
  checks. Rendering now requires PyYAML; bundle import/check remain stdlib-only.
- Casdoor `9d982e2d9f481666190517dd917fd5e6bf7bcd99` enforces application WebAuthn
  policy before establishing sessions. The product reviewer reports five tests
  with 49 subcases passing, six negative controls failing against the old
  handlers, and passing `go vet`, Clone/Lark/DeepCopy checks. Headscale and
  Headplane source revisions remain unchanged.

## Pending acceptance

Native candidate image builds and runtime validation, a Docker Compose v2 host
backup/restore rehearsal, published Feishu scopes with the first full lifecycle
apply, public DNS/TLS and both OIDC clients, reviewed ACLs and a two-device pilot
with live node/key expiry remain pending in this committed record. Headplane
session expiry, administrator credential rotation/MFA and operational monitoring
also require recorded acceptance.

The source lock remains `status: candidate` with
`compatibility_verified: false`. Existing RC3 manifests remain historical.
Final build identities, bundle checksum, exact source binding and execution
results belong in the private release inventory and bundle manifest after this
commit, avoiding a self-referential integration SHA. A synthetic isolated restore
cannot establish public OIDC, Feishu lifecycle or real-device pilot acceptance.
